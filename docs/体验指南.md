# 在家 InHome · 体验说明

在家 InHome 是装在 iPhone 里的家庭管家。随时看看家里的画面，读一读刚发生的事，重要的安排和安全变化也会及时提醒你。

## 打开体验

- [交互体验](../demo/在家InHome_iOS_Demo.html)：可交互的 iOS 产品界面。电脑中显示 iPhone 外观，手机窄屏中铺满页面。
- [App 介绍 Slides](../demo/在家InHome_正常运行流程_Slides.html)：16 页 App 介绍，约 7 分 55 秒，跟着一天的生活了解产品。

两个 HTML 都内嵌样式、脚本与图片，可以直接用浏览器打开。分享时把它们放在同一个文件夹，介绍页中的「体验在家」即可打开产品。


## 先看看家里

底部有「家、记忆、规则、扩展、设置」五个入口。首页可以选择「查看监控」，打开客厅或门口的画面。想看看宠物在做什么，或者确认门口情况，都能从这里进入。

监控会把观察到的活动整理成几句话，保存在「语义日志」里。每条记录都有发生时间与所在相机。点击记录，会直接打开对应画面，定位当时的关键时刻。

回看时可以播放、暂停、拖动时间轴，也可以逐个查看关键画面。「回到实时」会重新显示当前相机画面。记录支持按「全部、异常、日常」筛选和关键词搜索。

点击首页的异常提醒或锁屏通知，同样能直接进入对应监控。看过经过后，可以继续查看详情，确认「我已知晓」或「处理完成」。

## 把安排告诉在家

在「记忆」中选择「记下一件事」，输入「明天九点开会」之类的安排，确认事项与时间后保存。安排有变化时，可以修改时间或取消。

提醒到来后，选择「我已知晓」，后续跟进就会结束。事情办好后，再标记「处理完成」。重要事项从记下到结束，都有清楚的状态。

顶部可以切换「高效」与「陪伴」。高效适合专注重要事情，陪伴会偶尔分享家中的日常。在「规则」中，可以调整安静时段与提醒偏好。

## 抬手看一眼锁屏

点击手机顶部「锁屏」进入 iPhone 锁屏页面。「设置 → 锁屏与通知」提供独立选择：

- **常驻安全状态**：在锁屏上持续显示家中的状态、观察范围与更新时间。
- **状态变化弹窗**：家里有需要留意的变化时收到消息，轻点后打开对应监控。
- **生活消息**：陪伴模式下，偶尔收到一句与家中近况有关的日常话语。

比如团子在门边待了一会儿，锁屏上可能出现「团子在门边待了一会儿，可能有点想你了」。深夜仍在忙时，也可能遇见「很晚了，今天也辛苦啦，早点休息」。这些消息会自然出现在日常里，轻点就能看看相关画面。

生活消息在浏览应用时安静送达，锁屏后即可看到。已读或关闭的消息会收起。安全提醒优先呈现，生活消息遵循通知偏好与安静时段。常驻安全状态与状态变化通知的开关独立保留。

## 发现和分享扩展

「扩展 → 发现」展示官方与社区作品。先了解用途、作者和需要的权限，再选择添加。获取后的作品可以在「已添加」里统一管理。

自己有好点子，也可以创建一个扩展：

1. **Agent 协助**：描述想解决的生活小问题，整理成可编辑的作品草稿。
2. **提交代码**：输入或导入自己的 JavaScript 代码，补充名称、说明与权限。

保存后，作品会进入「我的作品」。提交审核后可以查看进度和修改意见，审核通过的作品进入官方仓库，其他用户也能获取使用。

## 完整走一遍

首页「体验流程」提供一段完整的生活故事：门口致谢、宠物饮水、记下安排、早晨提醒、明确回应、窗边查看、扩展与完成记录。自由探索时，也可以从「家庭场景」逐个查看。

生活消息会根据近期活动自动出现。家中有待确认的风险时，它会等到风险处理并留出一段时间后，再继续送来日常关心。宠物在门口等待的表达也会结合用户设置的「离家」状态。

当前状态保存在浏览器本地。电脑侧「重新开始体验」可恢复初始内容。

## 介绍页操作

- 左右方向键、空格或底部箭头翻页。
- `N` 显示讲解备注，`F` 请求全屏。
- 「目录」直接跳页，「自动播放」按每页讲解时长推进。
- 手机支持左右滑动，浏览器打印可输出横向页面。

## 当前交付范围

这份交付是纯 HTML 的 iOS 产品体验与 App 介绍，界面按正式产品设计呈现。原生 iOS 应用、真实设备连接与后台服务仍在开发范围内。

监控使用内嵌画面和本地事件时间线，语义日志由页面内的观察流程生成，关键画面按相机、事件与时间点对应。首次打开相机时，一段约 12 秒的观察会整理成一条记录。实际视频取流、视觉理解与设备控制需要后续连接。

日程输入使用有限句式解析，提醒、播报与联络进展由页面内交互呈现。真实语音输入、设备播报、电话和后台调度需要后续实现。

扩展草稿采用场景模板。创建、安装、审核与发布进度保存在浏览器本地，上传的代码作为文本保存。真实 Agent 服务、扩展运行环境、远程上传与官方审核平台需要后续连接。

锁屏、常驻区域与消息均由 HTML 界面呈现。原生 iOS 锁屏组件、实时活动与推送通知需要后续实现。生活消息由近期活动匹配、随机文案与频率限制生成，默认每天最多两条、间隔至少 90 分钟，待处理风险及恢复后的 30 分钟内暂缓。相关偏好和已读状态保存在浏览器本地。

当前交付可用于浏览器体验和设计评审。实体 iPhone、Safari 与真实硬件通道需要单独验证。
